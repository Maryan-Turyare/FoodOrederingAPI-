# FoodOrederingAPI

## Project Description
This is a Food Ordering System built using ASP.NET Core Web API and PostgreSQL.

## Features
- User Registration
- User Login with JWT Authentication
- Get All Foods
- Add New Food
- Unit Testing using xUnit

## Technologies Used
- ASP.NET Core
- PostgreSQL
- Entity Framework Core
- JWT Authentication
- xUnit
- Moq

## How to Run
1. dotnet restore
2. dotnet run

## Run Tests
dotnet test
